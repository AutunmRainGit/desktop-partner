# AI 工作根目录

本目录是 AI（Claude Code）在项目 `desktop-partner` 中的唯一工作根目录。
AI 产生的对话记忆、日志、代码与过程文件一律保存在本目录下，不写入系统其它位置（如 `~/.claude`）。

## 目录结构

- `memory/` — 对话记忆
- `logs/`   — 运行日志
- `work/`   — 工作文件（代码、过程文件）

## 工作规则（须始终遵守）

1. AI 对话记忆与日志只保存在本目录（不在系统其它地方保存）。
2. 工作文件（代码、过程文件）只保存在本目录（不在系统其它地方保存）。
3. 描述不清楚时，用中文向用户询问。
4. 不得修改或删除原有的非 AI 新建文件；若认为必须改动，须先通知用户。AI 生成的文件可以修改。
